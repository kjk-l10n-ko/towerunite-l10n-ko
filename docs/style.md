# 번역 스타일 — Tower Unite

## 톤

멀티플레이어 파티/소셜 게임. 대부분 UI 문구와 게임 내 알림·아이템 설명.
문장형 문구는 밝고 간결한 존댓말(`~하세요`, `~합니다`), 아이템 이름·설명은 명사형 종결
(`A wooden crate item for your condo.` → `콘도에 놓는 나무 상자 아이템.`).
플레이어 대상 경고/에러는 짧게: `You are banned` → `차단되었습니다`.

## UI 라벨·버튼

명사형, 2~6음절 우선. 대문자 강조(`!!`)는 느낌을 살려 유지.

## 형식 보존 (필수)

- 앞뒤 공백, `\r\n`, `{n}`, `%s`, HTML/XML 태그 그대로.
- 키 이름(`Tab`, `Ctrl`, `E`)은 번역하지 않음 (`Press E to` → `E 키를 눌러`).
- URL, 플레이어 이름 자리, 숫자는 그대로.
- 게임 이름 참고: Tower Unite → `타워 유나이트`,
  Little Charlers 등 개별 미니게임 이름은 원문 그대로 두는 것을 기본으로 (한국어 정착명이 있는 경우만 한국어).

## 고유명사

- Tower Unite → 타워 유나이트. 플라자(Plaza → 플라자), 콘도(Condo → 콘도).
- 플레이어 위주 단어: Winners/Players 등은 한국어.
