# Tower Unite 한글 패치 (4.22.3) (2026-10-29)

게임 **Tower Unite**(Steam, 4.22.3)의 비공식 한글 패치입니다.

* 작업/번역: Claude Sonnet 5.5/Deepseek v4 flash
* 검수: 김작가
* 오류, 오타는 kimjakka96@gmail.com로 제보해주시면 수정 배포하도록 하겠습니다.

## 설정 방법

설치 후 게임을 실행하면 바로 적용됨. (Windows 언어가 한국어인 경우 자동 적용)

게임에 언어 설정이 없으면 Windows 국가별 설정을 한국어로 두세요.

## 패치 내용

* 게임 텍스트(FText) 번역 (30428개 키)
* 게임 폴더에 한국어 번역 파일을 담은 `Tower/Content/Paks/zz_KoreanPatch_P.pak` 하나를 추가함.
  기존 게임 파일은 변경하지 않음.

원본 게임 파일은 변경되지 않으므로 별도 백업 없이 게임 폴더의 pak 하나만 삭제해도 원상복구됨.
